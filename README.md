Healthcare Service Platform

Web healthcare platform that connects users with significant medical centers, e.g., blood and organ donation, hospital information, ambulance appointment scheduling, and AI-driven analysis of medical reports.

Features

Blood & Organ Donation: Locate and connect with local donors.

Hospital Services Directory: Locate hospital information, including availability of OPD slots, doctors' qualifications, and whereabouts.

Ambulance Booking: Book ambulances through the platform.

Medical Report Analysis (Future): AI-driven tool for analyzing medicine prescriptions and scan reports.

Waste Disposal Management: Details about medical waste disposal services. 

Installation
Prerequisites
Install Node.js

Install MySQL

Steps to Run Locally
git clone https://github.com/GloryRP/healthcare-platform.git
cd healthcare-platform
npm install
npm start

Ensure MySQL is running before proceeding to start the backend.

Database Setup

1. Create a new MySQL database:
CREATE DATABASE healthcare_db;

2. Import the attached SQL schema to generate tables.

3. Update database credentials in backend configuration.

Tech Stack
Frontend: HTML, CSS, JavaScript, React

Backend: Node.js, Express.js
